# Finance Forecaster

Explainable financial analytics for personal bank statements. Upload a CSV; get
categorised transactions, detected recurring commitments, backtested cash-flow
forecasts with confidence intervals, an affordability model that tells you how to
improve, Monte Carlo and stress simulations, and outlier detection — every number
traceable to its inputs.
