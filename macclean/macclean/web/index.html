Safety levels

  • ✓ Safe Regenerable build and package caches. Preselected for you.
  • ! Review Probably fine, but look first (Trash, app caches, Docker build cache). Never preselected.
  • ✗ Dangerous Could lose real data (Docker volumes). Shown, never cleaned.

Some items are report only (Xcode Archives, simulators, stale node_modules, large files). macclean shows them but cannot delete them. Everything it does delete is checked against a list of protected folders (Documents, Desktop, Downloads, Photos, iCloud Drive, keychains, and more).
