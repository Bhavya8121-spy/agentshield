A checkpoint for your AI assistant.

More businesses let AI assistants answer customers, update orders and handle records. AgentShield checks every action the AI wants to take, stops the ones it shouldn’t, and keeps a record of what happened.

Think of the AI as a new employee

A new hire follows instructions fast, but can be tricked by a convincing note or a wrong request. You wouldn’t give them every key on day one. AgentShield is the manager who approves each move before it happens.

  • 1. The AI asksIt says what it wants to do, such as “look up this customer request.”
  • 2. AgentShield checksIs this person allowed to do that? Does the record belong to them?
  • 3. Approved or stoppedAllowed actions go through. The rest are blocked, and every decision is logged.

Watch an AI email assistant get tricked, then stopped

An AI assistant can read, send and delete email for you. Pick how easily it is fooled, ask it something, and see what would have happened with and without AgentShield. Every email here is fictional.

Tip: try “Summarize email 202” with the Gullible assistant and Full access. A hidden line inside that email tells the assistant to forward invoices to an attacker. Full access means a plain permission check would not object; AgentShield also checks that the action matches what you actually asked, and that mail only goes to your own company. The Simulated engine imitates a model with fixed rules; the Live engine calls a hosted model with a deliberately weakened prompt. AgentShield’s decision is computed the same way for both.

Bring your own email agent

Keep your agent where it is. When it wants to use a tool, send us only that tool call. AgentShield answers allow or deny before anything runs. We never contact your agent or see your keys.

  • 1. Your agent proposesCopy the tool call from your agent’s response (OpenAI, Anthropic or Gemini), for example send_email.
  • 2. You send it to usPaste it below, or call the API or SDK from your code.
  • 3. We decideYou only run the tool if the answer is ALLOW.
Wire it into your own code
Python SDK
from agentshield_sdk import AgentShield

shield = AgentShield("https://YOUR-DEMO-URL")
verdict = shield.check_agent_output(
    your_model_response,          # raw OpenAI / Anthropic / Gemini output
    role="admin",
    user_request="Summarize email 202.",
    domain="email",
)
if verdict.allowed:
    run_your_tool()               # only runs when every call is ALLOW

Where a small business would use it

If an AI tool can touch customer information, orders or money, it needs a checkpoint.

  • Online storeA chat assistant that can issue refunds or change orders.
  • Clinic or salonA booking assistant that reads and edits client appointments.
  • Accounting and bookkeepingAn assistant that reads invoices and records, where a hidden instruction in a document could cause harm.
  • Agencies and consultantsAn AI that handles several clients’ files and must never mix them up.
  • Software companiesTeams adding an AI assistant to their product. Their business customers increasingly ask for proof it has been tested.

Building your own AI assistant?

Developers can try the AgentShield Python SDK in minutes. Test a sample permission rule locally, or connect to the public synthetic demo. No Oracle account needed.

1. Install2. Check a proposed action3. Read the decision
Python SDK · local example
from agentshield_sdk import AgentShield

shield = AgentShield()
result = shield.check_local(
    role="reader",
    actor_tenant=10,
    resource_tenant=10,
    tool="delete_ticket",
)

print(result.allowed)  # False
print(result.reason)   # Tool not permitted for role

Developer preview only. The SDK uses a reference policy and fictional ticket IDs. It does not verify real users, inspect your agent automatically, or enforce permissions inside external applications. Production integrations require trusted identity and resource ownership checks.

Plain-English glossary

AI agent
An AI assistant that doesn’t just chat. It can take actions, like editing a record or issuing a refund.
Hidden instruction attack (prompt injection)
Sneaky text inside a message or document that tells the AI to do something its owner never asked for.
Separate customer accounts (multi-tenant)
When one system serves many businesses, each one’s data must stay private from the others.
Audit record
A log of what the AI asked for, what was decided and why, like a receipt for every action.
AgentShield is an early prototype. Our results come from small practice tests and do not guarantee that any AI is safe. It is not a security certification.
